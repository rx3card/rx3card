# Product

rx3card's GitHub profile: a visual work that lives at `github.com/rx3card`. Not a résumé, not a landing page, not a template.

## Platform

web

## Stack

GitHub-rendered Markdown with sanitized HTML, repository-hosted SVG, GIF and WebP. No JavaScript reaches the visitor. Python standard library and GitHub Actions generate everything from real data.

## Users

Anyone who lands on `github.com/rx3card`, usually for a few seconds, from a repository, a search or a link, on desktop or phone, in GitHub's dark or light theme. They arrive expecting a list of skills and find an atmosphere instead. The owner also uses it: the profile must keep itself alive without manual work.

## Product Purpose

Build the identity `rx3card` through experience rather than description. Success: a visitor remembers the place, not a job title, and every number they see is true.

## Positioning

Every advanced profile adds more cards. This one has a single world, one idea, and real data folded into it. It must not look automatically produced by any tool.

## Operating Context

GitHub's sanitizer strips scripts, styles and most attributes. Images render inside a column of roughly 830 px on desktop and 340 px on phones. Images in `<img>` cannot load external resources or receive input. Actions runs on a schedule and can be delayed.

## Capabilities and Constraints

- Language rankings by scope: GLOBAL, PUBLIC, PRIVATE, CONTRIBUTIONS, computed from Linguist bytes; contributions use their own explicit metric and are never mixed in.
- Contribution calendar visualized from real data, with one principal animation.
- Seasons: HALLOWEEN first, DARK as the permanent state, future seasons without rebuilding. Statistics stay independent of the theme.
- The owner approves everything public: no push, and no avatar, bio or status change without authorization.

## Brand Commitments

- The identity is `rx3card`. The owner's real name never leads.
- Forbidden: job titles, "Welcome to my GitHub", "Open to work", motivational lines, requests for followers or stars.
- Forbidden visually: cartoon pumpkins, smiling ghosts, childish GIFs, badge walls, repeated identical cards, seven near-identical eclipses, glow on everything, AI-looking images.
- Reference palette, not obligation: `#050507`, `#0B0B10`, `#FF6A00`, `#FF9A3C`, `#6E27A8`, `#ECECF2`.

## Evidence on Hand

Real, verifiable, and only these: public repositories with their real content, the GitHub contribution calendar, Linguist language bytes, and licensed archival images credited in `ASSET_SOURCES.md`.

## Product Principles

- Private repositories are invisible. Only aggregate language percentages leave the private scope; names, links, paths, ids, counts of repositories and raw data never do.
- Data is computed, never drawn by a model and never invented. If a refresh fails, the last valid result stands.
- Each element must justify its existence. If something weakens the whole, remove it.
- Movement carries meaning. Nothing moves merely to prove it can.
- The design speaks; it never explains who the owner is.

## Accessibility & Inclusion

WCAG AA contrast inside images, meaningful `alt` text on every image, no strobing, `prefers-reduced-motion` honored inside SVG, data legible on phones, and readable in GitHub's light theme.
